# الأحمدي للمقاولات

موقع عربي متجاوب لخدمات تأسيس وصيانة وتشطيب المنازل والفلل داخل مدينة الرياض.

## المحتوى

- 11 صفحة خدمة متخصصة
- 10 مقالات إرشادية أصلية
- صفحة تغطية تضم 74 اسم حي في الرياض
- أسئلة شائعة مخصصة وبيانات منظمة لكل نوع صفحة
- أزرار اتصال وواتساب مباشرة على الرقم `0555389493`

## التشغيل

```bash
npm install
npm run dev
```

## الفحص والبناء

```bash
npm run validate:content
npm run lint
npm run build
```

المشروع مبني باستخدام Next.js وReact، ومهيأ للنشر على Vercel.
